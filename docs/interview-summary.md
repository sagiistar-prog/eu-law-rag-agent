# Interview Summary

EU Law RAG Agent demonstrates a safe, source-grounded RAG workflow for legal and compliance research.

## What It Shows

- Ingestion of source-tagged Markdown documents.
- Chunk-level source metadata.
- Local keyword retrieval without external services.
- Refusal when no source is retrieved.
- Structured output with citations, confidence, limitations, and manual-review flags.
- A repository audit script for public portfolio safety.

## How To Explain It

The project is intentionally small, but it captures the control points that matter in compliance RAG: provenance, refusal behavior, review flags, and separation between evidence and inference.

## Important Boundary

This is not a legal advice system. It is a legal information retrieval and source-summary demo.
