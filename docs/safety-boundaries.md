# Safety Boundaries

## Public Portfolio Boundary

This repository is intended for public review. It must not include private commercial files, client records, partner records, internal documents, personal paths, credentials, or large raw source files.

## Legal Boundary

The project retrieves information and summarizes sources. It does not provide legal advice, legal opinions, legal representation, or professional services.

## Source Boundary

The system must answer only from retrieved sources. If no relevant source is found, it must refuse to answer and ask for source material.

## Review Boundary

Set `manual_review_required: true` for legal, tariff, customs, import, export, product compliance, enforcement, or commercial decision topics.

## Example Boundary

Examples must be fictional, short, and sanitized. Do not add full regulations, real business records, or large binary files.
