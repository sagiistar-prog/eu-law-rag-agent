# 官方条文与来源核对验收

验收日期：2026-09-18。范围是本地法规资料核对工作流，不是法律正确性、现行义务判断或用户业务效果。

## 用户可以完成的任务

选择 GDPR、DSA、DMA 或 AI Act，输入英文问题，查看相关摘录和完整选定条文，导出带来源、CELEX、日期、版本范围和待核对事项的 Markdown/JSON。修改查询或资料范围会清空旧结果，避免误导出。候选线索单独展开，不当作已支持的结论。

## 真实来源与构建

来源是欧盟出版局 Cellar 官方 XHTML，30 条选定原始公报条文，94,188 个清洗后字符。GDPR 12 条、DSA 8 条、DMA 4 条、AI Act 6 条。每份下载校验法规身份、条文 ID 和非空白字符覆盖；本次均为 1.0。覆盖检查只能发现提取遗漏，不证明法律版本完整或表格语义完全保真。

构建生成 350 个 chunk，真实 BGE small English 384 维编码。字符窗口 320、重叠 40；真实 tokenizer 最大观察值 83 token，模型限制 512。保留完整选定条文供人工核对条件。原文、向量与模型未提交仓库。

## 检索结果与调优代价

固定开发集 30 题：24 个有目标来源问题、6 个不应输出证据的问题。标注由实现者编写，不是独立专家标注；其中 22 个正向问题已指定法规范围。门槛也在该开发集上调整，存在过拟合。命中来源不证明摘录足够支持问题。

| 通道 | 调整后 Hit@5 | 调整后 MRR@5 | 误给证据 |
|---|---:|---:|---:|
| 本地 BM25 | 24/24 | 0.947917 | 0/6 |
| 本地向量 | 24/24 | 1.000000 | 0/6 |
| 本地混合 | 24/24 | 1.000000 | 0/6 |

混合检索来源 precision 为 0.504861，说明返回的多个来源仍可能不相关，不能将 Hit@5 当作答案准确率。组件延迟 P50/P95 约 46/85 ms，包含查询推理、不含模型加载和数据库，也未隔离硬件负载，不能视为生产 SLA。

调优前混合检索在 6 个资料缺失问题中有 5 个误给证据，向量通道为 2/6。修改常见词过滤、增加官方来源匹配门槛，并修复 PostgreSQL 关键词候选不在 dense Top20 时缺少余弦分数的问题。没有因此宣称混合检索必然优于 BM25。

### 额外改写失败

在最终真实 HTTP/数据库链路复测三个口语改写问题，目标条文进入支持证据为 **0/3**。GDPR 数据转移问题返回了访问权条文，目标 Article 20 只出现在候选；DSA 申诉和 AI Act 人工干预的问题也只有候选。这是未解决的相关性与召回缺陷。浏览器已验证可展开候选并读取目标 Article 20，但候选可查看不等于检索任务成功。

另两个资料缺失探针均未输出证据。这五题也是作者编写的补充探针，不是盲测或完整泛化评估。[完整记录](evaluation/official-paraphrase-probes.json)

下一步先建立独立改写、近似概念与时效冲突标注，再比较查询改写和重排。不能仅降低门槛来掩盖失败。

## 本地技术验收

| 范围 | 实际结果 |
|---|---|
| Python 知识管线 | 27/27，其中 4 项连接隔离 PostgreSQL |
| 旧插件输入输出 | 3/3，保留短 JSON 接口 |
| 官方来源 HTTP 与 PostgreSQL | 30/30，响应 Schema 和语料哈希一致 |
| CLI 结构化请求 | 使用同一真实模型导出 evidence.json 与 review.md |
| 无效 HTTP 输入 | 未知法规范围、额外字段均返回 400 |
| 插件结构与两个 Skill | 官方本地校验脚本通过 |
| 浏览器 1440px、390px | 完整条文、法规过滤、焦点返回、Markdown 导出、版本提示和无来源路径通过 |
| 浏览器异常恢复 | 明确模拟 503，问题保留、旧结果不可导出 |
| 自动可访问性 | 两个宽度 axe 违规 0、页面错误 0、横向溢出 0 |

[HTTP 逐题记录](evaluation/official-http-postgres.json) / [浏览器记录](evaluation/official-browser.json)

本地环境为 Windows 独立 CPython 3.10、ONNX Runtime 1.22.1、FastEmbed 0.7.4、PostgreSQL 16 / pgvector 0.8.1。浏览器为安装的 Chrome headless 的隔离临时上下文，不使用登录资料。本机没有该 Playwright 版本的配套 Chromium；CI 安装对应 Chromium 后验收。Conda 3.11 的 ONNX DLL 故障未修复，推荐独立 Python 环境。

自动可访问性结果不等于全量人工可访问性认证。真实数据库是本机隔离验收库，不是客户生产库。没有律师或目标用户参与，也没有客户价值或效率改善数据。

## 复现与发布检查

根 README 提供无数据库快速开始，knowledge/README.md 提供可选数据库命令。新增 [Official source review CI](../.github/workflows/official-review.yml) 重新下载官方条文和真实模型，运行三路评测、PostgreSQL HTTP 和浏览器任务。运行是否成功应以 GitHub 对应提交的检查为准。

发布流程：暂存变更，运行 portfolio_audit.ps1 -PreCommit；提交后运行 -BeforePush；推送后运行不带参数的严格审计，确认默认分支和对应提交检查。任何审计失败均停止发布。
